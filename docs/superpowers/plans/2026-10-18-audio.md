# 音频补齐实施与验收计划

目标：现有视频可以听到背景音乐和可选配音，预览和导出使用同一混音，刷新后保持项目设置。用户已要求补齐缺失音频功能，沿用已有APIMart和Cloudflare部署。

方案：父页面处理所有音频，AI动画iframe继续禁止媒体与网络。三种本站原创合成配乐默认选择Pulse，支持关闭、上传自己的音乐/配音、APIMart AI配音。音量独立控制，音乐在配音时降低音量，起止淡入淡出，音轨长度与视频一致。视频编码维持H.264，新增AAC音轨。

- [x] 音频引擎：确定性原创配乐、解码上传文件、混音/裁切/淡入淡出、AAC导出能力检查，测试非静音、削波、音量与时长。
- [x] 后端：私有音频R2与拥有者校验；项目音频设置独立表；APIMart配音600字符以内，每次20积分；幂等、失败退款、超时恢复。使用新增表迁移，保留现有数据。
- [x] 工作台：项目音频控件、配音文字/声线与上传、音量和错误状态；自动保存设置；预览按媒体时钟同步，暂停、seek、换项目、退出账号立即停止并清理。
- [x] 验收：现有测试、类型和构建检查；真实APIMart配音请求；正式浏览器导出有声MP4，ffprobe确认AAC并测量非静音；更新首页演示与交付记录，部署并推送GitHub。

共享协议位于shared/audio.ts。API约定：GET/PUT /api/projects/:id/audio；POST /api/audio/assets（multipart file）和GET /api/audio/assets/:id；POST /api/projects/:id/voice（text,voice,idempotencyKey），返回{asset,cost}。配音生成只创建音频素材，由UI明确绑定当前项目设置，避免迟到响应覆盖用户后来选择。

重点验证：跨用户访问；并发和重复TTS请求不重复扣点；文件伪造/超限；媒体长于视频时提示裁切；切换项目或退出后的迟到请求和声音；浏览器不支持AAC时明确报错而不静默输出无声视频。
