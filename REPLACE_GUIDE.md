# Content and asset replacement guide

This project keeps marketing copy, pricing data, brand, sample media and editor prompts in focused files. Replace only approved material; do not present a template illustration as an actual generated video.

| Content | Location | Replacement notes |
|---|---|---|
| Site name, SEO title, description, canonical URL | `index.html`; brand text in `src/Marketing.tsx` | Update canonical and metadata to the verified production hostname. Keep product/provider claims aligned with actual service behavior. |
| Logo mark / favicon | `src/Marketing.tsx` `Brand`; `public/favicon.svg` | The mark is inline/original. Replace both together and check light/dark contrast and small-size legibility. |
| Colors, typography, layout tokens | `src/styles.css` (`:root`, `--bg`, `--hot`, `--display`, `--wrap`) | Brand colors are near-black `#0b0b0b` and orange `#f06445`. Fonts currently load from Google Fonts; self-host or replace the `@import` if needed. Recheck responsive breakpoints after changing font metrics. |
| Main demo input/output | `public/demos/orbit-input.png`, `public/demos/orbit-poster.jpg`, `public/demos/orbit-demo.mp4` | Keep the media set synchronized. Current output is one actually generated 10-second orbit sample; do not substitute a stock/demo video while calling it generated by this product. Poster should be a frame of the corresponding MP4. |
| Example and effect cards | `src/lib/content.ts` (`templateData`, `effects`); page components in `src/Marketing.tsx` | Card illustrations in `src/Marketing.tsx` are original inline SVG/CSS motion studies, not separate finished video files. Label examples honestly. |
| Pricing display | `src/lib/content.ts` (`plans`), pricing content in `src/Marketing.tsx` | The UI values are USD monthly equivalent/annual total and credits. Keep in sync with Stripe Price IDs produced for the same environment and backend `worker/credits.ts`. Test test/live separately. |
| Legal, refund, support and contact copy | `src/Marketing.tsx` `LegalPage` and pricing FAQ | Support address currently uses `cuilinhao2015@gmail.com`. Failed generations return job credits; subscription charge questions are routed to support. Do not reintroduce a guaranteed cash refund promise unless approved and implemented. Review privacy retention/provider statements with the operator. |
| Studio templates and starter prompts | `src/lib/content.ts`; prompt controls in `src/Studio.tsx` | Presets set prompt, format and length; they do not correspond to distinct stored video outputs. Preserve supported values: 10/15/30 seconds, 16:9/9:16/1:1, up to four images. |
| API provider/model configuration | `wrangler.jsonc` `APIMART_MODEL`; Worker secret `APIMART_API_KEY` | Model ID is server-side configuration; never place keys in React, `VITE_*`, browser storage or public markdown. The implementation posts image and prompt content to APIMart. |
| Email sender / password recovery | `wrangler.jsonc` `EMAIL_FROM`, Send Email binding and Worker secrets/config | Delivery must be tested. The forgot-password endpoint returns 503 if email sending is not configured; do not display a successful-send message on failure. |
| Domain / deployment settings | `wrangler.jsonc`, `index.html` canonical URL | Keep `APP_URL`, canonical URL, Stripe redirect URLs, email reset URL and DNS/Worker routes in sync. A declared route is not proof that DNS or production routing is active. |

## Before publishing replacements

1. Confirm rights and source for every image, font, logo, video and testimonial. Do not copy Tellcut source code or third-party user posts into the product.
2. Run `npm run check`, `npm test` and `npm run build`; preview home, pricing, example, contact, reset-password and Studio routes at desktop and narrow viewport sizes.
3. Verify the demo video and poster are a matching pair; verify poster accessible text and provide working playback controls.
4. Confirm production domain routes, Stripe environment, webhook signature, customer portal, support inbox and email sender independently. Do not use live Stripe mode until merchant activation is complete.
5. Review copy against product reality: no subject segmentation or layer extraction is provided. Music and optional AI/uploaded narration are mixed in the browser; MP4 export requires compatible WebCodecs AVC/AAC support.
